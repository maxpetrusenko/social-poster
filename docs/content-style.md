# Content Language Evidence

Read when changing social generation, scheduled copy, RSS captions, LinkedIn templates, or agent-written drafts.

## Principle

There is no generic “Max voice” preset. Do not turn agent preferences, influencer patterns, or automated public posts into Max's language.

Use this evidence order:

1. `max_written`: exact wording Max wrote in a request, message, or known self-authored post.
2. `max_approved`: copy Max explicitly approved or edited into final form.
3. `source_required`: wording needed to state a verified source fact.
4. `generated_uncertain`: prior generated or automatically published copy with unknown approval.

Only `max_written` and `max_approved` are positive evidence of personal language. `source_required` can support factual copy. `generated_uncertain` must not train future tone.

## Observed, not mandatory

Known self-written examples can be brief and direct:

- “Who wants access to Kimi K3 model?”
- “I love codex for its computer use. I’m able to work with it in FileMaker Pro”
- “You might want to use this one.”
- “whatever tool you use just make sure it's taking advantage of everything models can do”

These examples show that plain wording is acceptable. They do not create permanent rules for lowercase, grammar, length, questions, or sentence shape.

## Drafting contract

- Separate Max's words from source words before drafting.
- Keep exact Max wording when it fits the platform and claim.
- Correct spelling for public copy when useful, without polishing the thought into a different persona.
- When Max has supplied no personal wording, produce neutral source-faithful copy.
- Do not invent a personal opinion, emotion, first-hand experience, hook, metaphor, thesis, or closing lesson.
- Do not add editorial decoration merely to make a post sound smarter.
- A user rejection applies to the current draft. Treat it as a global preference only when Max says it is global.
- Named accounts/authors can be research sources, never language templates.

## Current rejected additions

Do not regenerate these as filler in the Gauntlet or generic feed lanes:

- “actually inherit”
- “unusually concrete”
- “what stands out”
- “the interesting part”
- “builder takeaway”

The problem is provenance: these were agent additions presented as Max's language. A matching phrase may still appear when Max writes it or a source requires it.

## Platform and media

- Keep X concise when the fact is concise; use more room only when the source needs it.
- Give LinkedIn extra context only when it adds sourced information.
- Use real source media, verified OG images, or proof from Max's work.
- Never use decorative media as proof.
- Preserve source ownership and do not invent first-hand use.

## Review record

For generated drafts, retain enough internal metadata to answer:

- Which words came from Max?
- Which claims came from the source?
- What did the agent add?
- Was the copy approved, scheduled, or published?
