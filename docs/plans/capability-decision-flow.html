Capability Decision Flow

Account features become data first. The publisher reads capability status, confidence, and evidence before choosing text, image, video, long post, thread, or source-share.

input
Max likes an X post
Bird reads the liked post and captures source text, author, URL, and media hints.
lane
Classify intent
Repo bookmark, source-owned launch, video demo, opinion, or high-risk topic.
media
Pick media plan
Images snapshot. External links resolve OG images. Videos embed on X and upload on LinkedIn, with source in reply/comment.
capability
Load account graph
Check publish.text, image, video, long_text, thread, reply, and source_share.
decision
Preview then publish
Allowed plans get logged. Blocked plans show the missing capability before side effects.
publish.long_textMax account capability. Unknown for other X accounts until verified.
publish.link_preview_imageUsed for LinkedIn image recovery from external or GitHub links.
publish.source_shareUsed for video/demo likes: X embeds the original post URL and gets a source reply; LinkedIn receives an uploaded video and source comment.
confidenceobserved, verified, operator_confirmed, config, provider_default.
statussupported, unsupported, unknown, degraded.
evidencepublish result, connection test, provider default, or operator note.
