Info Tooltip Patterns

Each connection method gets an (i) icon. Clicking it shows a popover with setup instructions, requirements, and what capabilities it unlocks.

X OAuth 2.0 i

Setup Steps:
1. Go to developer.x.com
2. Create project + app
3. Enable "OAuth 2.0" under User Authentication
4. Set type: "Web App"
5. Add callback URL
6. Copy Client ID

Unlocks:
Posting Analytics DMs Replies

API Tier: Basic ($100/mo) or higher

LinkedIn OAuth i

Setup Steps:
1. Go to linkedin.com/developers
2. Create app under your company page
3. Request "Community Management" product
4. Add OAuth 2.0 redirect URL
5. Copy Client ID + Secret

Unlocks:
Posting Analytics Comments No DMs

Note: Company page requires admin access

Instagram via FB i

Setup Steps:
1. Create Meta App at developers.facebook.com
2. Add Instagram Graph API product
3. IG must be Business account (not Creator)
4. IG must link to a Facebook Page
5. Complete App Review for production

Unlocks:
Posting Analytics Comments DMs

Limit: 100 posts/day, tokens expire in 60 days

Plugin Hooks (Safety)

PreToolUse — Guardrail checks before executing. Confirms publish actions. Blocks credential exposure.
PostToolUse — Audit logging. Updates analytics cache. Triggers webhooks.

    |
    v

    |
    v

Store in cookie
    |
    v
Redirect to platform auth URL
    |
    v
User authorizes on platform
    |
    v
Platform redirects to callback
GET /api/auth/{platform}/callback?code=...
    |
    v
Exchange code for tokens
Fetch user profile
    |
    v
Store in DB: platforms table
  - access_token, refresh_token
  - profile info
  - capabilities
    |
    v
Redirect to /dashboard/platforms
Connection card appears

Credential Flow (Bluesky, Telegram)

User enters credentials in drawer
  - Bluesky: handle + app password

    v

    |
    v

  - Bluesky: createSession()
  - Telegram: getMe()
    |
    v
Store in DB: platforms table
  - session tokens
  - profile info
    |
    v
Drawer closes

Agent Tool Execution Flow

User: "Post to Twitter and check my LinkedIn analytics"
    |
    v
Agent Runtime receives message
    |
    v
LLM analyzes intent, decides on tools:
  1. post-tool (platform: "x", content: "...")
  2. analytics-tool (platform: "linkedin", dateRange: "7d")
    |
    v
[PreToolUse Plugin: Guardrail]
  - Confirms publish action with user? (configurable)
  - Validates no credential leakage
  - Checks rate limits
    |
    v
[Tool Execution via Platform Connector]
  post-tool --> X Module --> posting.ts --> Twitter API v2
  analytics-tool --> LinkedIn Module --> analytics.ts --> LinkedIn API
    |
    v
[PostToolUse Plugin: Audit]
  - Log execution to audit table
  - Cache analytics results
    |
    v
LLM formats results for user
    |
    v
Agent: "Posted to X: [url]. LinkedIn this week: 12K impressions..."

Implementation Phases

Phase 1

Foundation

Create _shared types. Platform folder stubs with re-exports. Unified registry. Backward compat shims.

Scope: L Deps: None
Phase 2

X/Twitter Deep

Full X implementation: analytics, DMs, comments, engagement, webhooks. Reference pattern for all platforms.

Scope: XL Deps: Phase 1
Phase 3

Connection UX

(i) tooltips, capability badges, flow explanations. Per-platform setup guides.

Scope: M Deps: Phase 1
Phase 4

Agent Harness

Tool system, platform connectors, runtime, plugins (guardrail + audit). Refactor social-agent endpoint.

Scope: XL Deps: Phase 2
Phase 5

Platform Expansion

Apply X depth to LinkedIn, Instagram, Facebook, Threads, TikTok, YouTube, Bluesky, Mastodon.

Scope: XL Deps: Phase 2
Phase 6

New Platforms

Reddit, Discord, Telegram with full depth from day one.

Scope: L Deps: Phase 1
