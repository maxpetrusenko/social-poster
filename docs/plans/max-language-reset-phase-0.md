# Max Language Reset — Phase 0

Date: 2026-07-22

## Problem

Social Poster and the global X-posting instructions accumulated editorial rules written by agents and labeled them as “Max voice.” The rejected examples in the Gauntlet draft (`actually inherit`, `unusually concrete`) came from agent-written editorial additions, not Max's source material. Public X history also contains automated posts, so it cannot be treated as an undifferentiated voice corpus.

## Target

Future X and LinkedIn copy should preserve Max's language without inventing a literary persona. Scheduled copy must be audited before its next run. No post is published as part of this reset.

## Evidence hierarchy

1. Exact wording Max writes in requests, messages, and clearly self-authored posts.
2. Copy Max explicitly approves or edits into final form.
3. Source-faithful facts and wording required for the subject.
4. Generated public posts, used only as negative or uncertain evidence unless authorship/approval is known.
5. Influencer or “inspired by” styles are not evidence of Max's voice.

## Smallest end-to-end slice

```text
real wording / explicit feedback
  -> evidence-labeled language notes
  -> generator prompt with no invented persona
  -> scheduled/future-copy audit
  -> draft-only verification
```

## Rules to remove

- Agent-created phrases presented as Max language.
- Broad banned-phrase inventories presented as a voice model.
- Named-account imitation lanes.
- Mandatory rhetorical shapes, camera positions, “angle boards,” and editorial endings unless Max asks for them.
- Claims that directness, negation, contrast, triads, lowercase, mistakes, or any other device is inherently Max's voice.

## Kept operational safeguards

- Source fidelity and claim verification.
- No invented first-hand experience.
- Platform/media validation.
- Review and publish authorization gates.
- Exact user corrections override generator defaults.

## Proof gates

- Global and repo prompts describe evidence labels, not a manufactured persona.
- Tests cover the evidence hierarchy and rejected agent-authored phrasing.
- Every enabled fixed schedule and queued future post is inspected for affected language.
- Production changes, if needed, are backed up and verified read-only afterward.
- Published count remains unchanged.
