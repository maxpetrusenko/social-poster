Canonical Page Reference

Per-page flows and nested operator paths.

Use this while coding nav, shells, nested tabs, and page actions. Structure: shell → page → nested flow groups.

Workspace Shell

Daily operator shell. BrightBean IA plus your automation pages.

Publish

brightbean core calendar + list posts + approvals + sent

Workspace → Publish → switch `Calendar` or `List` → list tabs `Queue / Drafts / Approvals / Sent` → open post → edit / schedule / approve / publish / inspect publish log.

Create Idea

composer core current create-post

Workspace → Create Idea → idea landing / templates / feeds → full composer → channel select → media → per-channel tweaks → `Save Draft / Submit for Approval / Schedule / Publish Now`.

Social Inbox

brightbean core replies debug stays

Workspace → Social Inbox → `All / My Queue / Unassigned` → open conversation → assign / label / saved reply / SLA state / reply.

Replies

social-poster keep

Workspace → Replies → X reply-engine log → sent/failed metrics → event detail → open reply URL. Keep until inbox parity fully replaces debug need.

Schedules

social-poster keep

Workspace → Schedules → list cadence → enable/disable → inspect next fire, drift, success rate → open schedule detail → run now / edit / delete.

Categories

social-poster keep

Workspace → Categories → inspect content buckets → see live schedule count → add slot → jump into schedule creation.

Notifications

brightbean core activity sources

Workspace/global bell → notification drawer/history → mark read → open item → deep link to publish error, approval, inbox assignment, or account issue.

Channels

brightbean shell connections drawer

Sidebar channel section → healthy/unhealthy account rows → open Social Accounts or reconnect → Add Channel → method picker → connect → verify → visible connected icon.

Publish nested flows

  • Calendar mode: planned + actual runs.
  • List mode Queue: next-up content lanes.
  • Drafts: saved, not scheduled.
  • Approvals: pending internal/client states.
  • Sent: published posts plus publish log.

Create Idea nested flows

  • Idea landing.
  • Template or feed seed.
  • Composer body.
  • Channel-specific variants.
  • Validation and preview.

Connection nested flows

  • Add channel.
  • Pick platform.
  • Pick connect method.
  • Verify capabilities.
  • Jump straight into composer.

Org Settings Shell

Top-level admin shell above any single workspace.

Profile

Settings → Profile → avatar / name / account details / password / session controls later.

Preferences

Settings → Preferences → timezone, density, notification delivery, personal defaults.

General

Settings → General → org name / logo / timezone / branding / defaults / deletion flow.

Workspaces

Settings → Workspaces → create / archive / restore / open workspace settings / switch context.

Users

Settings → Users → modal invite / Admin or User role / resend / revoke / remove.

All Calendars

Settings → All Calendars → cross-workspace scheduled view, grouped by workspace.

Media Library

Settings → Media Library → shared org assets, folders, reuse, lifecycle control.

Workspace Settings Shell

Brand/client-specific control plane.

General

Workspace Settings → General → brand colors, timezone, workspace defaults, archive state.

Social Accounts

Workspace Settings → Social Accounts → connected grid/list → add, reconnect, test, disconnect, invite client to connect.

Media Library

Workspace Settings → Media Library → workspace assets, folders, search, reuse in composer.

Approvals

Workspace Settings → Approvals → mode, reminders, routing, approver policy, client review requirements.

Client Portal

Workspace Settings → Client Portal → invite client, portal links, pending invites, access rules, published visibility.

Client Portal Shell

Magic-link review surface for clients.

Home

Magic link → Home → summary cards → jump into Approvals, Published, Activity.

Approvals

Portal → Approvals → open pending post → preview media/caption → approve / request changes / reject / comment.

Published

Portal → Published → see live content, links, timestamps, and later reports.

Activity

Portal → Activity → client-visible approval history and decision trail.
