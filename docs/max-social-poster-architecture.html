2 · PROCESS — Dedup + Rank + Signal Detection

Dedup Engine

Normalize URLs, fuzzy-match titles (Levenshtein). If same story appears in 3+ feeds → popularity signal. Merge into single canonical item.

Rank & Score

Score = (source_count × 3) + recency_bonus + keyword_match + engagement_proxy. Top N candidates per workflow. Configurable thresholds.

Content Router

Route items to workflows: breaking news → AI News Repost. Visual/demo → TikTok. Opinion/hot-take → Engagement Post. Lifestyle/behind-scenes → IG Story.

1. AI News Repost

Schedule: 9:00 AM + 5:00 PM UTC · Platforms: X, LinkedIn, Facebook, Reddit
How it works:
→ Pull 50-100 RSS feeds in one batch (feedparser, ~2s total)
→ Normalize & dedup: same URL or title similarity > 0.85 → merge
→ Score: stories appearing in 3+ feeds get 3× boost (virality signal)
→ Pick top 2 stories → generate tweet: hook + insight + link
→ Post via Zernio API to X account petrusenko_max
→ Cross-post adapted versions to LinkedIn, Facebook, Reddit
→ Log URL to dedup store to prevent re-posting
XLinkedInFacebookReddit

2. TikTok AI News

Schedule: 12:00 PM UTC · Platforms: TikTok, IG Reels
How it works:
→ Same feed pipeline, but filter for stories with visual demos, launches, or wow-factor
→ Generate 30-60s video script with hook-in-2-seconds format
→ Use existing video generation pipeline (TTS + template) or screen recording
→ Upload via Zernio to TikTok + Instagram Reels
→ Hashtags auto-generated from topic keywords
TikTokIG Reels

3. Daily Engagement Post

Schedule: 2:00 PM UTC · Platforms: X, LinkedIn
How it works:
→ Pick hottest topic from today's feed (highest cross-feed score)
→ Generate contrarian take, hot question, or "unpopular opinion" format
→ Optimized for replies/engagement, not clicks
→ Post to X + LinkedIn with platform-specific formatting
→ No links — pure engagement bait (in a good way)
XLinkedIn

4. Daily IG Story

Schedule: 7:00 PM UTC · Platforms: IG Story, FB Story
How it works:
→ Structured template (consistent brand):
  • Top bar: "Day N of building [project]"
  • Screenshot or photo of work-in-progress
  • 1-liner insight or "TIL" takeaway
  • Poll or question sticker for engagement
→ Can be auto-generated from git commits or manual photo drop
→ Post via Zernio Stories API
