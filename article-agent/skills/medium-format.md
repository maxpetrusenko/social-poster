# Medium Format Skill

Medium-ready article defaults:
- Strong title, optional subtitle, then direct answer.
- Short paragraphs.
- H2 sections every 250-450 words.
- One hero image and relevant alt text.
- Links embedded naturally in sentences.
- No front matter unless explicitly requested.
- End with a conclusion that loops back to the opening tension.
- Blockquotes are for definitions, direct answers, and FAQ answers. Do not wrap prose blockquotes in fenced code blocks. If a blockquote sentence wraps across multiple Markdown lines, collapse it back into one paragraph before Medium export.
- Fenced code blocks are only for real code or literal snippets. Never use them as visual quote/callout formatting for normal article prose.

Medium footer / bio:
- If footer or bio is enabled, the final Medium-ready Markdown must include Max's Medium automation footer.
- Do not invent a new author bio.
- If an external Medium automation worker appends the footer after generation, do not duplicate it in the body.
- For standalone article folders, append this exact footer:
